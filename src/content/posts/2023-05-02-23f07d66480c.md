我們可以在 Cloudflare 後台查看各種 Log 與圖表，今天來介紹一下，有哪些功能可以使用，目前這些 Log 功能都需要 Pro 以上授權才能使用。

* * *

#### 一、網路安全事件紀錄

[前幾篇](https://medium.com/chouhsiang/30%E5%A4%A9%E6%90%9E%E6%87%82cloudflare-10-waf-a917272cbb55)有講到 WAF 的功能，在付費功能中，我們可以將所有流量進行紀錄，就可以在 Cloudflare Dashboard 查看紀錄。

我們到「網路安全」的「WAF」，新增一筆防火牆規則，選擇所有 HTTPS 的輸入，並記錄下來。

![](/images/medium/e999a5d31d92f6e8.png)

再來到「網路安全」的「事件」，就可以查看網路流量的 Log，介面如下，可以看到時間軸的圖表、來源資料整理、每個紀錄的細節。

![](/images/medium/09bfc5fc7794aabb.png)

![](/images/medium/be7ad0bbeaf662ab.png)

![](/images/medium/36cb31498e575e9e.png)

* * *

#### 二、即時紀錄

在「分析與紀錄」中的「即時紀錄」點擊開始串流，就可以查看目前的即時資訊，即時紀錄不會被儲存下來，網頁重新整理後就會不見。

![](/images/medium/6fe421e8fefb4d02.png)

* * *

#### 三、Log Push

Log Push 可將網站的日誌數據推送到第三方存儲和分析工具中。它可以幫助您更好地瞭解您的網站訪問者和網站流量，從而幫助您做出更好的決策和優化網站性能。

![](/images/medium/9ae2c6d0a0c84f3f.png)

選擇新增 Logpush 後，可以選擇要送出 log 的種類，包含 Cloudflare 的操作紀錄。

![](/images/medium/fb3a967149883e83.png)

再來選擇要送出的欄位。

![](/images/medium/40831fa51df3f8bf.png)

下一步選擇目的地，可以與各種存儲和分析工具整合，例如 AWS S3、Google Cloud Storage、Splunk 和 Sumo Logic 等。這使您能夠使用自己的分析工具和過程來進行數據分析，而不是使用 Cloudflare 的內置分析功能。

![](/images/medium/4fcbd6258c73b2c7.png)

* * *

#### 四、Log Pull

如果你的環境不適合使用 Log Push，可以考慮使用 Log Pull，需要自行撰寫程式並呼叫 Cloudflare API 讀取 Log，更多資料參考[官方文件](https://developers.cloudflare.com/logs/logpull/)。

![](/images/medium/dcf6e397d9a00f11.png)

* * *

#### 結語

Cloudflare 提供多種收集 Log 方式提供管理員更好的分析與紀錄問題。

我們在M1或M2的MacOS上打包Docker image會發現包出來都是ARM版，會無法在x86\_64上執行，我們可以透過設定，強制每次打包的時候都用amd64。

***

#### 語法

通常base image都會支援各種[指令集架構](https://docs.docker.com/build/building/multi-platform/)，我們可以透過指令以某個指令集打包，如以下是使用amd64打包。

```bash
docker buildx build --platform linux/amd64 -t test:latest .
```

如果要每次下docker指令預設就用amd64，可以在shell profile新增這行，預設macOS加到\~/.zprofile。

```bash
export DOCKER_DEFAULT_PLATFORM=linux/amd64
```

在Docker應用程式中也可以看到拉下來的image被標記成amd64

Cloudflare Web Analytics 是 Cloudflare 所提供的一項網站流量統計分析工具，透過這個工具，網站擁有者可以追蹤網站的訪問量、來源、使用者行為等資訊，以協助他們更好地瞭解網站使用者的需求和行為，並做出相應的優化和改善。Web Analytics 功能類似於坊間常用的 Google Analytics，如果要在所有網站部署 GA 可以參考 [Zaraz 這篇](https://medium.com/chouhsiang/30%E5%A4%A9%E6%90%9E%E6%87%82cloudflare-15-zaraz-62c02f6a0254)。

與其他網站分析工具不同的是，Cloudflare Web Analytics 是基於 Cloudflare 的全球分佈式網路來統計分析數據，不僅可以提供即時的數據分析，同時也能夠確保數據的準確性和可靠性。

Cloudflare Web Analytics 支援多種不同的分析報告，例如：

1.  **訪問量報告**：顯示網站的訪問量、瀏覽量、網頁停留時間等訪問相關的數據。
2.  **來源報告**：顯示網站的訪問者來源，例如搜尋引擎、社交媒體、廣告等。
3.  **使用者行為報告**：顯示網站訪問者的行為，例如瀏覽器型號、設備解析度、操作系統等。
4.  **地理位置報告**：顯示網站訪問者的地理位置分佈情況。
5.  **網頁性能報告**：顯示網站的網頁加載速度、請求量、頁面大小等性能相關的數據。

除了以上報告外，Cloudflare Web Analytics 還支援自定義報告，使用者可以根據自己的需求創建和設置報告。此外，Cloudflare Web Analytics 還支援數據可視化展示，通過圖表、表格等形式將數據直觀地呈現出來，方便使用者進行數據分析和決策。

#### 結語

Cloudflare Web Analytics 是一個功能強大、易於使用的網站分析工具，能夠幫助網站擁有者深入瞭解其網站使用者的需求和行為，以提高網站的訪問量和用戶體驗。

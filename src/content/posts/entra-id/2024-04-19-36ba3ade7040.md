我們可以透過 Entra ID 應用程式註冊(App registration)產生用戶端密碼(Secret)，透過 API 存取 Entra ID上的資料，使用手法參考[這篇](https://medium.com/chouhsiang/%E9%96%8B%E7%99%BC%E4%BB%8B%E6%8E%A5azure-ad-2-%E4%BD%BF%E7%94%A8%E8%80%85%E6%B8%85%E5%96%AE-b3d29ec5f7b5)。但是當 Secret 外洩，任何取得 Secret 的人就可以訪問 Entra ID 上的資料，本篇將說明如何限制訪問的 IP，保護應用程式註冊。

* * *

### 授權

我們需要透過條件式存取(Conditional Access)來做限制，因此我們需要有 [Entra ID P1/P2](https://www.microsoft.com/zh-tw/security/business/microsoft-entra-pricing) 的授權，如果是 M365 帳號，則本來就有這功能。

![](/images/medium/e8af90f05f218193.png)

P1/P2 本身並沒有限制應用程式訪問 IP 的功能，因此還要另外購買 [Entra 工作負載 ID](https://www.microsoft.com/zh-tw/security/business/microsoft-entra-pricing#x16843c17894b4152aefa3f72e129aedb) (Workload ID)。

![](/images/medium/2742e2667d6d2cc2.png)

工作負載 ID 中有個功能叫條件式存取增強安全性，才能限制訪問 IP。

![](/images/medium/2d24c0b1a57818e1.png)

* * *

### 建立信任 IP 清單

到 Azure 後台 > 條件式存取 > 具名位置 > 新增 IP 範圍位置

![](/images/medium/c6018f7b9e4b76ae.png)

* * *

### 設定限制 IP 存取

到 Azure 後台 > 條件式存取 > 原則 > 新原則。會發現可以選擇服務主體，如果沒有 Workload ID 授權，是沒辦法選擇服務主體的。

![](/images/medium/6baec735e6491d5e.png)

目標資源，選擇所有雲端應用程式

![](/images/medium/9c441654e09ea697.png)

選擇包括任何位置，並排除剛剛建立的信任位置

![](/images/medium/99007b6a0f118598.png)

存取控制的授與選擇封鎖存取，這樣就完成了。

![](/images/medium/abc351f8895d1d4d.png)

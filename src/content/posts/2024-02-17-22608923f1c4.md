### /decrypt Request

HiPKI Local Server /decrypt 用於資料解密，支援 PKCS1、PKCS7 的密文。

```shell
POST http://127.0.0.1:61161/decrypt
Content-Type: text/plain

tbsPackage={"pin":"000000","cipher":"qwqwqw","cipherType":"PKCS7",
"plainEncoding":"none","keyidb64":"S0VZWA=="}
```

必填欄位：

*   **cipher** `必填`  
    密文
*   **pin** `必填`  
    卡片 PIN 碼

選填欄位：

*   **cipherType** `選填`  
    密文類型  
    ▶ 選項：PKCS7、PKCS1  
    ▶ 預設：PKCS7
*   **plainEncoding** `選填`  
    回傳明文的編碼  
    ▶ 選項：none、base64  
    ▶ 預設：none
*   **keyidb64** `選填`  
    公鑰 ID 的 Base64  
    ▶ 預設：S0VZWA== (KEYX，加密用公鑰)  
    ▶ 選項：S0VZWA== (KEYX，加密用公鑰)、U0lHTg== (SIGN，簽章用公鑰)、U0lHTjAy (SIGN02，隱藏公鑰)

* * *

### /decrypt Response

當解密成功的時候，會回傳以下資訊。

```bash
HTTP 200 OK
Content-Type: text/plain; charset=utf-8

{"func":"decrypt","last_error":0,"plain":"ZGNzZGNzZGM=",
"ret_code":0,"version":"2.4.5"}
```

欄位說明：

*   func：API 名稱
*   last\_error：固定回傳 0
*   plain：解密完的明文
*   ret\_code：簽章成功會回傳 0
*   version：可能是程式的版號

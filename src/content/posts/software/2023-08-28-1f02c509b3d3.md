這幾天有個新聞，某強國將VSCode換皮、改Logo，並加上儲值的功能，叫做CEC-IDE，可以看看[知乎](https://www.zhihu.com/question/619023882)、[Github](https://github.com/microsoft/vscode/issues/191229)的討論串，讓我對VSCode開源感到興趣，查了一些資料並整理。

* * *

目前VSCode有三個版本分別為：VSCode（Visual Studio Code）、VSCodium 和 Code-OSS ，它們之間有一些差異。以下是它們的主要區別：

#### 1\. [VSCode](https://code.visualstudio.com/)

Visual Studio Code 是由微軟開發的一款免費的IDE，支援多種程式語言和框架。它提供了豐富的功能，像是智慧型程式碼補完、除錯、Git 整合、擴充功能支援等。VSCode 是閉源的，但是使用者可以免費使用。另外還有[線上版](https://code.visualstudio.com/docs/editor/vscode-web)可以用。

#### 2\. [VSCodium](https://github.com/VSCodium/vscodium)

VSCodium 是 VSCode 的一個克隆專案，由社群維護。不同於 VSCode，VSCodium 是開源的，因此它的程式碼是公開的，任何人都可以查看、修改和散佈。由於 VSCode 本身雖然功能強大，但包含了一些與微軟的服務和追蹤相關的元件，所以一些使用者對於隱私和資料收集問題感到擔憂。VSCodium 解決了這些問題，提供了一個更加注重隱私的版本，保留了 VSCode 的功能並移除了與追蹤相關的部分。

#### 3\. [Code-OSS](https://github.com/microsoft/vscode)

Code-OSS 是 Visual Studio Code 的開源版本，由微軟開發並維護。它是以 MIT 授權條款發布的，這表示任何人都可以自由查看、使用、修改和散佈它的程式碼。不同於 VSCodium，Code-OSS 與原始的 VSCode 程式碼更為相似，仍然保留了微軟的一些特性和服務。

Cloudflare 提供一系列檔案託管服務，如果不想用三大雲的檔案系統，也可以考慮 Cloudflare，包含與 S3 相容的 R2、影片串流的 Stream、圖床的Images。由於這些功能我也沒在 Cloudflare 用過 😀，只能節錄官網資訊跟大家介紹一下。

* * *

#### Cloudflare R2

R2 是個零輸出費用的物件儲存空間，可讓您透過與 S3 相容的物件儲存空間，建立心目中的多雲端架構。根據官網說明他有以下特性：全球物件儲存空間、與 Cloudflare Workers 整合實現動態功能、透過我們與 S3 相容的 API 避免廠商鎖定、透過現有雲端儲存提供者輕鬆遷移。

![](/images/medium/730d89af8a06f203.png)

* * *

#### Cloudflare Stream

Cloudflare Stream 無伺服器即時串流和隨需影片串流，上傳、儲存、編碼及傳遞**即時和點播視訊**，全都使用一個 API。

![](/images/medium/ef927ac0c3c14d87.png)

* * *

#### Cloudflare Images

Cloudflare Images 提供簡單直接的端到端解決方案，用於經濟高效地構建和維護您的影像基礎結構。使用單一產品對影像進行大規模存儲、大小調整和優化。

![](/images/medium/27fafba24db66c67.png)

* * *

#### 結語

透過結合 Cloudflare CDN 網路，將檔案部署在邊緣節點上，可以有效提升使用者體驗，我是沒相關需求用不到，有用過的人歡迎分享一下！

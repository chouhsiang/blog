* * *

本文會說明如何將自己的網域註冊到 Cloudflare 上，並開始使用 Cloudflare。首先需要將您的域名設定到 Cloudflare 上。以下是一些簡單的步驟，可以幫助您完成這項任務。

* * *

#### 步驟 1：註冊 Cloudflare 帳戶

首先，您需要[註冊](https://dash.cloudflare.com/sign-up)一個 Cloudflare 帳戶。註冊過程非常簡單，只需要提供您的電子郵件地址和密碼即可。在完成註冊後，您將進 入Cloudflare 的[Dashboard](https://dash.cloudflare.com/)。

![](/images/medium/12b37f9dd5b262de.png)

* * *

#### 步驟 2：購買網域

您可以使用在 GoDaddy 或 Gandi 購買的網域，下一步將 DNS 交給 Cloudflare 代管，或是在 Cloudflare 的網域註冊中購買。

![](/images/medium/4fefa8e98d8bd5ae.png)

* * *

#### 步驟 3：新增網站

接下來，您需要將您的網站新增到 Cloudflare 上。在 Dashboard 中，點擊「新增網站」按鈕，然後輸入您的網域，選擇免費方案。接下來，Cloudflare 會掃描您的網站，確定它是否已經在他們的系統中存在。

如果網站還沒有在 Cloudflare 系統中註冊，您需要手動設置 DNS 紀錄，請依 Cloudflare 網站上說明設定 NS 紀錄，Cloudflare 會自動掃描現有的 DNS 紀錄，如果有錯誤或遺漏的地方，請更正或新增，所以建議先從舊的 DNS 伺服器匯出紀錄。

![](/images/medium/975dd62f595b91cf.png)

* * *

#### 步驟 4：查看儀表板

當你的網域 NS 設定到 Cloudflare 後，就會看到網域狀態是使用中，免費方案沒有限制網域數量，可以一直增加。

![](/images/medium/3034fd2150b0cb23.png)

若是不希望整個網域的 DNS 都交給 Cloudflare 管理，也不想修改 NS 紀錄，可以透 過CNAME 方式將網域交給 Cloudflare 管理，需要 Business 以上的授權才能使用，詳見[官方文件](https://developers.cloudflare.com/dns/zone-setups/partial-setup/)。

* * *

#### 結語

將域名設定到 Cloudflare 上是一個非常簡單的過程，只需要簡單的操作就能完成。使用 Cloudflare 的服務可以為你的網站提供更高的安全性和性能，同時還能節省成本和時間，讓你的網站更加穩定和快速。

如果你還沒有使用 Cloudflare 的服務，現在就去試試吧！

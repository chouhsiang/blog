[上一篇](https://medium.com/chouhsiang/30%E5%A4%A9%E6%90%9E%E6%87%82cloudflare-18-%E9%9B%BB%E5%AD%90%E9%83%B5%E4%BB%B6-cb4353babfd8)我們講到 Cloudflare 電子郵件相關的功能，本篇將說明 Cloudflare 中電子郵件防護的服務 Area 1，Area 1 是需要額外購買的服務。

Cloudflare Area 1 能夠保護使用者收件匣的安全、採行主動式安全狀態，並節省電子郵件安全作業的時間，透過在攻擊週期的最初階段阻止網路釣魚，全面抵禦複雜的威脅。

Area 1 除了整合自建的電子郵件伺服器外，也支援整合 Gmail、M365 等商用軟體。目前市面上電子郵件防護軟體，主要是有下兩種方式進行防護，這邊來說明一下。

* * *

#### MX 式防護

我們可以將 Area 1 架設於原本的 MX 伺服器之前，避免郵件伺服器暴露在外，郵件經過掃描後，才會往後傳到收件夾，可以有效的阻擋不安全的郵件，但缺點為需要修改原本的 MX 入口，並調整電子郵件架構，更多資料可以參考[官方文件](https://developers.cloudflare.com/email-security/deployment/inline/)。

其他同樣方式防護產品有：[Openfind MailGates](https://www.openfind.com.tw/taiwan/mailgates.html)、[趨勢 DDEI](https://www.trendmicro.com/zh_tw/business/products/user-protection/sps/email-and-collaboration/email-inspector.html)、[Cellopoint](https://www.cellopoint.com/solutions-phishing?lang=zh) 等產品。

* * *

#### API 式防護

API 式的防護主要是針對市售產品如 Gmail、M365 等，不需要修改原先 MX 紀錄，透過 API 方式將郵件進行掃描，缺點由於信件會先進入收件夾，才進行掃描，可能會有時間差在未掃描之前就點入郵件。更多資料可以參考[官方文件。](https://developers.cloudflare.com/email-security/deployment/api/)

其他同樣方式防護產品有：[趨勢 Cloud App Security](https://www.trendmicro.com/zh_hk/business/products/user-protection/sps/email-and-collaboration/cloud-app-security.html)、[Cellopoint](https://www.cellopoint.com/microsoft-office-365?lang=zh) 等產品。

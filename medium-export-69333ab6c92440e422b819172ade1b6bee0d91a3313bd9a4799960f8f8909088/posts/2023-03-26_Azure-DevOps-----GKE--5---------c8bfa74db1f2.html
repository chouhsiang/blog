gcloud指令

再來到電腦開個console，輸入以下語法登入，以json檔登入

# 先安裝好 gcloud、kubectl、docker

gcloud components install gke-gcloud-auth-plugin   # kubectl用到的Plugin

gcloud auth login --cred-file XXX.json

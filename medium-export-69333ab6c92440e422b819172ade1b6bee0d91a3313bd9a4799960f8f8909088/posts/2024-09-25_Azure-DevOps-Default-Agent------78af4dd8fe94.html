Azure DevOps Default Agent 系統資訊

以下為 Azure DevOps Default Agent 系統資訊

Pipeline 執行角色

系統以 vsts 使用者執行腳本

  • UID：1001(vsts)
  • GID：127(docker)
  • Groups：127(docker),4(adm),101(systemd-journal)
  • 家目錄：/home/vsvts
  • Shell：Bash

Agent 主機上的路徑

/home/vsts/work/1/s

Pipeline 預設執行路徑，並會自動下載原始碼到此

系統變數：System.DefaultWorkingDirectory、Build.Repository.LocalPath、Build.SourcesDirectory

/home/vsts/work/1/a

將任何成品複製到其目的地之前，代理程式上的本機路徑

系統變數：Build.ArtifactStagingDirectory、Build.StagingDirectory

/home/vsts/work/1/b

代理程式上的本機路徑，您可以做為已編譯二進位檔的輸出資料夾

系統變數：Build.BinariesDirectory

/home/vsts/work/1/TestResults

建立測試結果之代理程式的本機路徑

系統變數：Common.TestResultsDirectory

「貓咪和湯」優惠券序號自動登錄機器人

貓咪和湯有個優惠券序號兌換的功能，到兌換網站輸入會員編號與序號就可以兌換獎品，但每次都要手動輸入很麻煩，我就寫個 Github 腳本，每天自動檢查有沒有新的序號，並兌換。

安裝方式

你需要先註冊一個 Github 帳號，Github 有個功能叫做 Github Actions，Actions 可以設定排程定時執行腳本。

1. 對我寫好的腳本點擊 Fork，選好帳號後點擊 Create Fork

2. Fork 完後，點擊 userid 檔案，點擊右上角編輯按鈕，將內容改成自己的貓咪和湯會員編號，並存檔。

3. 點擊 Settings > Actions > General ，勾選 Read and write permissions 並儲存，這裏用來記錄兌換過哪些序號，並回寫到 Repo

4. 啟用 Github Actions，點擊「I understand my workflows, go ahead and emable them」，再來選擇「Register」，點選「Enable workflow」

5. 安裝完成

這樣就完成了，每天台灣時間早上八點會執行一次，到 .github 資料夾下可以找到一個自己序號的 log，這裡會放已經兌換過的序號。run.log 則是放腳本執行的紀錄。另外也可以點「Run workflow」手動執行腳本。

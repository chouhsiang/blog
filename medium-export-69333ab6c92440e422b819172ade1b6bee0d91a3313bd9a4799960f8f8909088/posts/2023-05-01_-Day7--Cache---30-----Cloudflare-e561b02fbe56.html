[Day7] Cache — 30 天入門 Cloudflare

我們會需要 CDN，主要是希望避免伺服器被攻擊、減輕伺服器運算壓力，此時便會用到 Cache 來暫存內容。

Cloudflare Cache 是 Cloudflare CDN 的一部分，它使用全球分佈式的 CDN 網路，在全球節點上快速存儲和傳遞您的網站內容。Cache 通常是指存儲在 CDN 節點中的靜態內容，例如圖像、CSS、JavaScript 檔案等。

Cloudflare Cache 可以大幅提高網站的載入速度，減少伺服器的負載，從而改善使用者體驗和 SEO。當有人造訪您的網站時，他們的請求首先會被發送到 Cloudflare CDN 上最近的節點，如果該節點中已經存有您的網站內容，那麼 CDN 節點會立即返回網站內容，而不是去您的伺服器上讀取。這樣可以節省大量時間和帶寬。更多 Cloudflare Cache 說明可以看官方文件。

Cache 設定

預設 Cloudflare 就會幫你開啟快取，也可以在後台調整快取的設定，如手動清除快取、快取等級，您可以設定 Cloudflare 的 CDN 將靜態內容依下列等級加入快取：

  • 無查詢字串：僅在無查詢字串時從快取傳遞檔案。
  • 忽略查詢字串：無論查詢字串，向所有人都傳遞相同資源。
  • 標準：依查詢字串變化，每次供應不同資源。

要注意的是，Cloudflare 預設並不快取 HTML 內容。若有需要，可建立網頁規則來快取靜態 HTML 內容。

從官方文件中可以知道，決定會不會被 Cache 是看檔案的副檔名，只有以下副檔名的檔案會被快取，而會看到除了 JS、CSS、圖片外，很多檔案也都會被 Cache，若是某些檔案需要後端檢查權限才能取得，則應將檔案路徑略過快取，避免檔案外洩。

另外還有 Always Online 功能，當網站壞掉的時候可以使用 Web Archive 撐一段時間；如果正在開發中，不需要網站被 Cache 就可以開啟開發模式。

Cache Rules

如果要修改 Cache 規則，有兩個方法可以做到，第一個方法是，在 Caching 的 Cache Rules 可以設定要快取或不快取的規則。

第二個方法是在規則的網頁規則中也能設定快取規則。

Node.js crypto 其他語法

除了 Web Crypto API crypto.subtle.verify，Node.js 另外支援 crypto.verify、crypto.createVerify 驗證方法；而 Cloudflare Workers 只支援 Web Crypto API ，所以上面範例以此為主，以下為另外兩種的寫法。Cloudflare Workers 支援的 crypto 語法，詳見官方文件。

在 crypto.verify、crypto.createVerify，SHA 演算法表示法為 SHA256，而crypto.subtle 則為 SHA-256，中間會多一槓。

crypto.createVerify

// 沿用上述範例參數 cert, attrBuf, sigBuf, hashAlgo
const certPem = forge.pki.certificateToPem(cert);
const algo = hashAlgo.replace("-", "");

const verify = crypto.createVerify(algo);
verify.update(attrBuf);
if (verify.verify(certPem, sigBuf)) {
  console.log("PKCS7 驗簽成功");
} else {
  console.log("PKCS7 驗簽失敗");
}

crypto.verify

// 沿用上述範例參數 cert, attrBuf, sigBuf, hashAlgo
const certPem = forge.pki.certificateToPem(cert);
const algo = hashAlgo.replace("-", "");

const verify = crypto.verify(algo, attrBuf, certPem, sigBuf);
if (verify) {
  console.log("PKCS7 驗簽成功");
} else {
  console.log("PKCS7 驗簽失敗");
}

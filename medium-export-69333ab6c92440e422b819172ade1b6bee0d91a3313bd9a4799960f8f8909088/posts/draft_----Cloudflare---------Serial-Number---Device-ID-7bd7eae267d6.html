迷惑的 Cloudflare 零信任設備驗證 Serial Number 與 Device ID

最近在研究如何識別已知的設備，並決定能不能訪問受零信任保護的服務。開始研究如何識別設備編號，才發現這方式太讓人迷惑了。

Cloudflare WARP 

我們可以透過 Cloudflare WARP 來取得設備資訊，並以此在 Cloudflare Access 上設定規則是否能訪問服務。

目前支援了以下幾種作業系統：

  • 電腦 OS：Windows、macOS、Linux
  • 移動 OS：Android、iOS / iPadOS、ChromeOS

設備登入變連線 Cloudflare WARP 後，可以在後台查看到 Serial Number 與 Device ID。

可知道的資訊如下：

  • OS：可以得知使用的作業系統與版本
  • Serial Number：主機板序號，詳見官方文件
  • Device ID：Cloudflare 發放的裝置唯一識別 ID
